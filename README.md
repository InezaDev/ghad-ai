# GHAD AI — AI-Powered Educational Platform

AI-first lesson planning, teaching assistance, assessment generation and methodology recommendations for teachers in Rwanda. Built on the REB Competence-Based Curriculum framework.

## Tech Stack

- **Frontend**: Vanilla HTML / CSS / JavaScript (no build step)
- **Backend**: Vercel Serverless Functions (`/api` directory, Node.js 18+)
- **AI**: DeepSeek API (`deepseek-flash`, OpenAI-compatible)
- **Deployment**: Vercel (static + serverless)
